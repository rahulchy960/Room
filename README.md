# Room

Room is a Discord-inspired real-time chat and community app focused on servers, channels, DMs, and calls.

## Key Features (Planned)

- Real-time messaging using Socket.io
- Send attachments as messages using UploadThing
- Delete and edit messages in real time for all users
- Create text, audio, and video call channels
- 1:1 conversations between members
- 1:1 video calls between members
- Member management (kick, role changes: Guest / Moderator)
- Unique invite link generation with a full working invite system
- Infinite loading for messages in batches of 10 (@tanstack/query)
- Server creation and customization
- Beautiful UI using TailwindCSS, Tweakcn, and ShadcnUI
- Full responsiveness and mobile UI
- Light / Dark mode
- WebSocket fallback: polling with alerts
- ORM using Prisma
- PostgreSQL database using NeonDB
- Authentication with Clerk
